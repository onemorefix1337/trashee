# trashee

Неофициальный кроссплатформенный клиент Яндекс Музыки для macOS, Windows и Linux.
Electron, React и TypeScript.

> trashee не связан с Яндексом. Он использует закрытое API сервиса, как это делают другие
> сторонние клиенты, и Яндекс может изменить его без предупреждения. Для проверок лучше
> завести запасной аккаунт.

## Что умеет

- Моя волна и бесконечное радио, поиск, любимые треки, плейлисты (свои и чужие), альбомы, исполнители.
- Закреплённое из официального приложения в боковой панели, закрепление и открепление.
- Тексты песен: строки идут вместе с песней, по клику на строку можно перемотать.
- Мини-плеер поверх всех окон: обложка, трек, кнопки управления. Открывается из боковой панели
  или по ⌘/Ctrl + Alt + M, место выбирается в настройках, карточку можно перетащить.
- «Похожие» треки отдельной страницей, «Не нравится» и возврат прежней очереди после замены.
- Десятиполосный эквалайзер, скорость воспроизведения, качество звука.
- Медиаклавиши и системный плеер: Now Playing на macOS, SMTC на Windows, MPRIS на Linux.
- Цвета по обложке, визуализатор, анимации (их уровень настраивается).

## Горячие клавиши

| Клавиша          | Действие                     |
| ---------------- | ---------------------------- |
| Пробел           | Пауза и воспроизведение      |
| ← →              | Перемотка на 5 секунд        |
| ⌘/Ctrl + ← →     | Предыдущий и следующий трек  |
| ⌘/Ctrl + K       | Поиск                        |
| L                | Лайк текущему треку          |
| D                | Не нравится: пропустить трек |
| Alt + ←          | Назад по страницам           |
| ⌘/Ctrl + Alt + M | Мини-плеер поверх всех окон  |

## Установка

Готовые установщики появляются на странице Releases после выпуска версии.

Приложение пока не подписано, поэтому система предупредит о неизвестном разработчике:

- **macOS.** Открой dmg, перетащи trashee в «Программы». При первом запуске открой его через
  правый клик и «Открыть», либо выполни `xattr -cr /Applications/trashee.app`.
- **Windows.** SmartScreen покажет «Windows защитила ваш компьютер». Нажми «Подробнее», затем
  «Выполнить в любом случае».
- **Linux.** Сделай AppImage исполняемым: `chmod +x trashee-*.AppImage`.

При первом запуске нажми «Войти через Яндекс»: приложение откроет страницу Яндекса, где нужно ввести
показанный код. Пароль trashee не видит, токен хранится в системной связке ключей.

## Разработка

```bash
npm install
npm run dev
```

| Команда                                           | Что делает                                      |
| ------------------------------------------------- | ----------------------------------------------- |
| `npm run dev`                                     | Запуск с горячей перезагрузкой                  |
| `npm run lint`                                    | ESLint и Prettier                               |
| `npm run typecheck`                               | Проверка типов                                  |
| `npm test`                                        | Тесты на встроенном раннере Node                |
| `npm run icons`                                   | Перегенерировать иконки из `resources/icon.svg` |
| `npm run build:mac` / `build:win` / `build:linux` | Установщики в папке `dist`                      |

Нужен Node.js 22.18 или новее (тесты запускаются без сборки, на TypeScript).

## Устройство проекта

```
src/main/        процесс Electron: окно, IPC, API Яндекс Музыки, поток аудио
src/main/yandex/ клиент API, подпись запросов, расшифровка потока, разбор ответов
src/preload/     мост между окном и main
src/renderer/    интерфейс на React: страницы, плеер, настройки
src/shared/      типы и чистая логика, общая для main и renderer (её проверяют тесты)
scripts/         генерация иконок и брендинг dev-сборки
```

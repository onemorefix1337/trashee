# Сайт trashee

Статический сайт: один `index.html`, стили, скрипт и картинки. Сборка не нужна, внешних библиотек и шрифтов нет.

```
index.html      страница
style.css       оформление (те же цвета и градиент, что в приложении)
script.js       анимации, показ скриншотов, кнопки скачивания
assets/         логотип, значки, превью для соцсетей, скриншоты в assets/shots/
```

## Посмотреть у себя

Открой `index.html` двойным щелчком. Или запусти маленький сервер в этой папке:

```bash
python3 -m http.server 8080
```

и зайди на http://localhost:8080.

## Как работают кнопки скачивания

Скрипт спрашивает у GitHub последний релиз `onemorefix1337/trashee`, находит в нём файлы под каждую систему и ставит их в кнопки вместе с размером и версией. Название файла содержит версию, поэтому новые релизы подхватываются сами, сайт править не нужно.

Если GitHub недоступен, кнопки ведут на страницу последнего релиза. Другой репозиторий указывается в начале `script.js`, в константе `REPO`.

## Выложить в интернет

Подойдёт любой хостинг статики: Netlify, Cloudflare Pages, Vercel, GitHub Pages. Достаточно перетащить папку `site`.

- **GitHub Pages.** Сайт публикуется из этой папки workflow'ом `.github/workflows/pages.yml` при каждом пуше в `main`, который меняет что-то в `site/`. В настройках репозитория: Settings → Pages → Source: GitHub Actions.
- **Домен.** Адрес `trashee.ru` указан в файле `CNAME`, в `og:image`, `og:url` и `canonical` в `index.html`. Если домен поменяется, замени его во всех четырёх местах.
- **DNS** (в Cloudflare): четыре записи `A` и четыре `AAAA` для `trashee.ru` на адреса GitHub Pages и `CNAME` для `www` на `onemorefix1337.github.io`. Пока GitHub выпускает сертификат, облачко у записей должно быть серым (DNS only).
